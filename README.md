# 基于 51 单片机的智能窗户控制系统

基于 STC89C52 的智能窗户控制系统：采集光照与温度，按光照阈值、定时或高温条件自动控制步进电机开合窗帘；LCD1602 配合按键菜单可设置各项参数，设置掉电保存在片内 EEPROM。

河北工程技术学院 电子信息工程专业课程设计（2025.10 – 2025.12），团队作业，**课程设计获优秀评分**。

## 功能

* **光照自动控制**：ADC0832 采集光照强度，低于 / 高于设定阈值自动关帘 / 开帘，响应时间 < 2 秒
* **定时控制**：DS1302 实时时钟，可设定开帘与关帘时间
* **高温报警**：DS18B20 采集温度，超过设定值（默认 35°C）触发蜂鸣器
* **手动 / 自动模式切换**，支持按键直接控制
* **LCD1602 多级菜单**：设置光照阈值、开关帘时间、报警温度、电机参数等
* **参数掉电保存**：设置写入 STC89C52 片内 EEPROM，重启后保持

## 硬件

|器件|型号|说明|
|-|-|-|
|主控|STC89C52（8051 内核）|Keil C51 编译|
|光照采集|ADC0832|8 位串行 ADC，前端接光敏电阻|
|温度采集|DS18B20|单总线数字温度传感器|
|实时时钟|DS1302|掉电走时|
|显示|LCD1602|字符型液晶|
|执行机构|步进电机 + ULN2003|驱动窗帘开合|
|提示|蜂鸣器、LED|报警与状态指示|
|仿真|Proteus|`.pdsprj` 工程|

## 引脚分配

|引脚|功能|
|-|-|
|P1^7|蜂鸣器|
|P2^7|灯光 / LED 模块|
|P3^7 / P3^6 / P3^5|ADC0832 DO / SCL / CS|
|P3^1 / P3^2|按键：加 / 减|

其余引脚见各驱动头文件中的 `sbit` 定义。

## 目录结构

```
自动窗帘代码/
├── 智能窗户.c                          # 主程序：初始化、EEPROM 读写、主循环
├── menu.h / menu\_1.h / menu\_2.h / menu\_value.h   # LCD 多级菜单系统
├── lcd1602.h                           # LCD1602 显示驱动
├── bujindianji.h                       # 步进电机驱动
├── ds1302.h                            # DS1302 实时时钟驱动
├── 18b20\_2lu.h                         # DS18B20 温度采集
├── eepom52.h                           # STC89C52 片内 EEPROM 读写
└── key.h                               # 按键扫描
```

## 编译与烧录

1. 用 Keil C51 打开 `智能窗户.uvproj`
2. 编译（F7），生成 `智能窗户.hex`
3. 用 STC-ISP 通过串口下载
